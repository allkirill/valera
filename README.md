📸 Фотоукладчик Валера
Мощный десктопный помощник для автоматизации скачивания, обработки и упаковки фотографий. Идеально подходит для контент-менеджеров, фотографов и маркетплейсов (с встроенным пресетом для santehnica.ru и др.).

Написан на Python с использованием PySide6 (Qt). Оптимизирован для работы на слабых ПК и SSD с минимальным потреблением оперативной памяти.

✨ Ключевые возможности
🌐 Скачивание и интеграция
Источники: Локальные папки или Excel-таблица (.xlsx).
Облачные хранилища: Автоматическое разрешение коротких ссылок Яндекс.Диска и Облака Mail.ru.
Многопоточность: Параллельное скачивание (2 потока для баланса скорости и ОЗУ).
Умный Excel: Автоматическое извлечение ссылок из ячеек, цветовая индикация статусов (Зеленый — ОК, Желтый — размер, Синий — фон, Красный — ошибка скачивания).
🖼 Обработка и анализ
Умный фон: Автоматическое определение белого фона (255) и сероватого фона (240-254).
Центрирование: Обрезка полей и центрирование объекта в квадрат с настраиваемым отступом.
Итеративная обрезка (Пороги): При повторной обработке порог определения фона снижается (255 → 240 → 220...), позволяя обрезать всё более серые края.
Контроль размера: Проверка мин/макс разрешения по длинной стороне с контролем процента увеличения.
PDF поддержка: Многостраничные PDF сохраняются как есть, одностраничные — конвертируются в квадратные фото.
Водяной знак: Наложение полупрозрачного логотипа в правый нижний угол.
Метаданные: Автоматическая очистка EXIF по желанию.
🛠 Ручная постобработка (Предпросмотр)
Визуальный просмотр отбракованных фото с фильтрами по категориям.
Действия над выбранными файлами:
✂ Обрезать поля
⬜ Центрировать в квадрат
🔍 Сократить отступ (увеличить объект, обрезав края, с сохранением мин. размера)
↩ Вернуть исходник
🗑 Удалить
Мульти-отмена: Поддержка Ctrl+Z для всех действий в окне предпросмотра.

📖 Как пользоваться (Алгоритм)
Выберите источник: Укажите Excel-таблицу с ссылками или Папку с фото.
Место назначения: Укажите, куда сохранить результат (по умолчанию — Рабочий стол).
Настройте параметры: Выберите пресет (например, santehnica.ru) или настройте вручную формат, минимальный размер и процент отступа.
ЗАПУСТИТЬ: Программа скачает, обработает и разложит фото по папкам.
Постобработка: Если есть ошибки или фото с серым фоном, появится оранжевая кнопка ⚡ Проверить отбракованные.
Принудительное преобразование: В окне предпросмотра выделите проблемные фото и нажмите ⚡ Преобразовать. С каждым нажатием порог определения фона ослабляется (255→240→220...), что позволяет срезать всё более серые поля.

⚙️ Зависимости
Основные библиотеки, используемые в проекте:
